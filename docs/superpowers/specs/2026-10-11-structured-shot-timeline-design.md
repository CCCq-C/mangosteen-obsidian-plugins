# 结构化分镜时间轴设计

## 目标

把每个分镜的主要编辑内容改为“按剧情节点动态划分的时间轴”，由系统自动编译最终视频提示词。用户不再重复维护剧情、台词、情绪、镜头语言、首帧、尾帧和视频提示词等多套内容。

人物一致性始终由人物三视图资产保障；场景和产品也继续使用独立参考资产。

## 用户界面

每个分镜保留标题、时长、场景和产品选择。展开后显示若干可增删的时间轴行，每行包含：

- 开始时间与结束时间
- 画面动作
- 人物台词
- 情绪与声音
- 景别与运镜
- 环境

时间段由 AI 根据剧情节点自动划分，不使用固定的 `0～1秒、1～4秒` 模板。用户可以编辑时间和内容，也可以新增或删除时间段。

旧的“首帧提示词”“尾帧提示词”“视频提示词”和重复的平铺字段不再作为主要编辑入口。确认生成前展示系统编译出的完整视频提示词，只读预览仍是实际提交内容。

## 数据结构

生成草案升级为版本 4。每个镜头新增：

```json
{
  "id": "001",
  "title": "人物展示耳机",
  "duration": 14,
  "sceneId": "living_room",
  "productIds": ["headphones"],
  "timeline": [
    {
      "start": 0,
      "end": 3,
      "action": "人物走入客厅并看向镜头",
      "dialogue": "",
      "performance": "神态自然，脚步放松",
      "camera": "远景跟拍，逐渐过渡到中景",
      "environment": "傍晚客厅，暖色灯光"
    }
  ]
}
```

校验规则：

1. 第一段从 0 秒开始，最后一段结束时间等于镜头总时长。
2. 相邻段首尾相接，不能重叠或漏秒。
3. 每段结束时间必须大于开始时间。
4. 时间段数量不固定，按剧情复杂度确定。
5. 镜头总时长继续遵守所选视频模型的整数秒限制。

旧版 1～3 草案在读取时自动转换为单段时间轴，避免旧项目无法打开。

## 提示词编译

新增独立的时间轴编译模块。它只负责校验时间轴、生成首帧画面描述和编译最终视频提示词。

最终提示词顺序为：

1. 人物一致性和参考图使用规则。
2. 全片固定声音设定。
3. 按时间顺序输出每段动作、台词、表演声音、景别运镜和环境。
4. 明确禁止改写台词，要求口型同步，背景音乐不得盖过对白。

用户手写的完整提示词覆盖仍保留为兼容能力，但不在主界面突出显示。

## 模型自适应参考方式

### MiniMax H3

MiniMax H3 使用首尾帧接口，不能直接接收独立人物、场景和产品参考图。为保证人物一致性，系统根据人物三视图、场景图、产品图和时间轴第一段自动生成一张首帧，再提交首帧和时间轴提示词。默认不生成尾帧，也不要求用户填写首尾帧提示词。

### Seedance 2.5

Seedance 2.5 直接把人物三视图、场景图和产品图作为参考图片提交，同时提交时间轴提示词，不再生成每个镜头的首帧或尾帧。

## 队列和安全边界

确认生成时，时间轴、参考资产、模型设置和编译后的最终提示词一起进入不可变快照。队列中的镜头不受后续编辑影响；未进入队列的镜头继续可编辑。

正在运行的旧队列不迁移、不改写，也不因插件源代码更新而中断。新逻辑只作用于重新保存并确认的新任务。

## 错误处理

- 时间轴存在空档、重叠或越界时，不允许确认生成，并定位到对应时间段。
- 所选模型不支持当前参考方式时，停止提交并提示更换模型。
- 人物三视图缺失时，不允许提交任何强调人物一致性的镜头。
- 平台返回错误时，保留不可变队列和已生成资产，允许用户修改失败镜头后重新确认。

## 验收标准

1. AI 能输出按剧情节点动态划分的结构化时间轴。
2. 用户能在分镜卡片中增删改时间轴行。
3. 时间轴校验能阻止空档、重叠和总时长不一致。
4. 确认弹窗展示的提示词与平台收到的提示词一致。
5. MiniMax H3 仅自动生成首帧，Seedance 2.5 不生成首尾帧。
6. 两种模型都强制复用同一人物三视图资产。
7. 旧版项目仍可打开、编辑并重新生成。
